# CaspianDentos · Калькулятор окупаемости инвестиций

Изолированный, легко встраиваемый модуль для **Dental OS** — мгновенный расчёт
срока окупаемости инвестиций в стоматологическую клинику.

> Формула: `срок (мес.) = Сумма пакета ÷ (Средний чек × Процедур в месяц)`

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | Готовая страница-демо (React + framer-motion + Tailwind через CDN, без сборки). Это то, что публикуется на Vercel. |
| `CaspianDentosROI.jsx` | Чистый, переиспользуемый React-компонент для встраивания в любой проект со сборкой (Vite / Next / CRA). |
| `platform.html` | Прежнее демо Caspian Platform (HR / Time / Payroll), сохранено без изменений. |

## Возможности

- **Два поля ввода** со «валютной маской» — средний чек и сумма пакета.
- **Слайдер** количества процедур в месяц (1–100).
- **Расчёт на лету** (Optimistic UI) — без кнопки «Рассчитать».
- **Анимация чисел** через `framer-motion` (плавный спринг).
- **Дизайн** в стиле Stripe: минимализм, мягкие тени, скруглённые углы.

## Встраивание в проект со сборкой

```bash
npm i react react-dom framer-motion
# Tailwind должен быть настроен в проекте
```

```jsx
import { CaspianDentosROI } from "./CaspianDentosROI";

export default function Page() {
  return (
    <CaspianDentosROI
      currency="₸"
      defaultCheck={85000}
      defaultPackage={2400000}
      defaultPerMonth={12}
      onChange={({ months, monthlyRevenue }) => {
        // подписка на пересчёт, если нужно
      }}
    />
  );
}
```

### Пропсы

| Проп | По умолчанию | Описание |
| --- | --- | --- |
| `currency` | `"₸"` | Символ валюты |
| `locale` | `"ru-RU"` | Локаль форматирования чисел |
| `defaultCheck` | `85000` | Начальный средний чек |
| `defaultPackage` | `2400000` | Начальная сумма пакета / инвестиций |
| `defaultPerMonth` | `12` | Начальное число процедур в месяц |
| `onChange` | — | Колбэк, вызывается при каждом пересчёте |
| `className` | `""` | Доп. классы внешнего контейнера |

## Локальный запуск демо

Это статический файл — никакой сборки не нужно:

```bash
npx serve .
# затем откройте http://localhost:3000
```
